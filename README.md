# مدرسة الريحان للعلوم الشرعية 🕌

منصة تعليمية إلكترونية شاملة متخصصة في تعليم الفقه المالكي والعلوم الشرعية. تتميز المنصة بتصميم عصري ومتجاوب مع جميع الأجهزة، مع دعم كامل للغة العربية ووضع ليلي مريح للعين.

## 🌟 الميزات الرئيسية

### 📚 نظام إدارة التعلم (LMS)
- **إدارة المقررات الدراسية**: إنشاء وتحرير المقررات مع تنظيمها حسب العلوم الشرعية
- **دروس تفاعلية**: دروس مرئية (فيديو) ومسموعة (صوت) مع مرفقات PDF
- **نظام المستويات**: تنظيم الطلاب حسب المستويات مع إمكانية الوصول الهرمي للمحتوى
- **تتبع التقدم**: نظام متقدم لمتابعة تقدم الطالب في كل مقرر ودرس
- **الملاحظات الشخصية**: إمكانية تدوين الملاحظات لكل درس
- **نظام الأسئلة والأجوبة**: الطلاب يطرحون الأسئلة والمعلمون يجيبون عليها

### 🎨 التصميم والواجهة
- **تصميم متجاوب**: يعمل بشكل مثالي على جميع الأجهزة (الحاسوب، التابلت، الهاتف)
- **الوضع الليلي**: تصميم داكن مريح للعين للاستخدام الليلي
- **دعم RTL كامل**: دعم كامل للغة العربية من اليمين إلى اليسار
- **ألوان إسلامية**: نظام ألوان أخضر متناسق مستوحى من التراث الإسلامي
- **تجربة مستخدم سلسة**: تصميم حديث وسهل الاستخدام

### 👥 إدارة المستخدمين
- **أدوار متعددة**: مدير، معلم، طالب
- **المدير فقط يضيف المستخدمين**: لا يوجد تسجيل عام
- **لوحات تحكم مخصصة**: لوحة تحكم مخصصة لكل دور
- **صلاحيات محددة**: تحكم دقيق في صلاحيات كل مستخدم

### 📊 التقارير والإحصائيات
- **تقارير التقدم**: تقارير مفصلة عن تقدم كل طالب
- **إحصائيات شاملة**: إحصائيات عن الطلاب والمقررات والدروس
- **تقارير الأسئلة**: متابعة الأسئلة المطروحة والمجابة

### 🔔 التواصل
- **نموذج اتصال متقدم**: نموذج اتصال يرسل إلى rayhaneschool@gmail.com
- **صفحة البحث**: بحث متقدم مع فلاتر متعددة
- **صفحة 404 مخصصة**: صفحة خطأ 404 جميلة مع روابط مفيدة

## 📦 المحتويات

المشروع يتكون من جزأين رئيسيين:

### 1. القالب (Theme): `fiqhlearning-theme`
- `style.css` - ملف الأنماط الرئيسي
- `functions.php` - وظائف القالب
- `header.php`, `footer.php` - الرأس والتذييل
- `front-page.php` - الصفحة الرئيسية
- `archive-fiqh_course.php` - صفحة المقررات
- `single-fiqh_course.php` - صفحة المقرر الواحد
- `single-fiqh_lesson.php` - صفحة الدرس
- `single.php` - صفحة المقال مع Hero Section
- `page-login.php` - صفحة تسجيل الدخول
- `page-contact.php` - صفحة اتصل بنا
- `page-about.php` - صفحة عن المدرسة مع Timeline
- `search.php` - صفحة البحث
- `404.php` - صفحة الخطأ 404

### 2. المكوّن الإضافي (Plugin): `fiqhlearning-lms-plugin`
- نظام إدارة المقررات والدروس
- نظام التسجيل في المقررات
- نظام تتبع التقدم
- نظام الأسئلة والأجوبة
- نظام الملاحظات
- لوحة تحكم الإدارة

## 🚀 التثبيت والإعداد

### المتطلبات
- WordPress 6.0 أو أحدث
- PHP 7.4 أو أحدث
- MySQL 5.7 أو أحدث

### خطوات التثبيت

#### 1. رفع الملفات
```bash
# رفع القالب
wp-content/themes/fiqhlearning-theme/

# رفع المكوّن
wp-content/plugins/fiqhlearning-lms-plugin/
```

#### 2. تفعيل المكوّن الإضافي
1. اذهب إلى لوحة التحكم → الإضافات
2. فعّل إضافة "FiqhLearning LMS"

#### 3. تفعيل القالب
1. اذهب إلى لوحة التحكم → المظهر → القوالب
2. فعّل قالب "مدرسة الريحان"

#### 4. إعداد الصفحات الأساسية
قم بإنشاء الصفحات التالية:

- **الصفحة الرئيسية**: اختر قالب "Front Page"
- **تسجيل الدخول**: اختر قالب "تسجيل الدخول"
- **اتصل بنا**: اختر قالب "اتصل بنا"
- **لوحة التحكم**: اختر قالب "Dashboard"

#### 5. إعداد القوائم
1. اذهب إلى المظهر → القوائم
2. أنشئ قائمة رئيسية وأضف إليها:
   - الصفحة الرئيسية
   - المقررات
   - عن المدرسة
   - اتصل بنا

#### 6. التخصيص
اذهب إلى المظهر → تخصيص لضبط:
- الشعار
- الألوان
- نصوص الصفحة الرئيسية
- روابط التواصل الاجتماعي

## 📧 إعداد البريد الإلكتروني

نموذج "اتصل بنا" يرسل الرسائل إلى: **rayhaneschool@gmail.com**

لضمان عمل إرسال البريد بشكل صحيح:

### الطريقة 1: استخدام SMTP (موصى به)
1. قم بتثبيت إضافة WP Mail SMTP
2. اذهب إلى WP Mail SMTP → Settings
3. اختر Gmail كمزود الخدمة
4. أدخل بيانات البريد الإلكتروني

### الطريقة 2: استخدام إضافة Easy WP SMTP
1. قم بتثبيت إضافة Easy WP SMTP
2. أدخل معلومات SMTP الخاصة بك

### الطريقة 3: تكوين PHP mail
تأكد من أن الخادم الخاص بك يدعم دالة `mail()` في PHP

## 👥 إدارة المستخدمين

### إضافة مستخدم جديد

#### من لوحة التحكم
1. اذهب إلى المستخدمون → إضافة جديد
2. أدخل معلومات المستخدم
3. اختر الدور المناسب:
   - **طالب (Student)**: للطلاب
   - **معلم (Teacher)**: للمعلمين
   - **مدير (Administrator)**: للإدارة

#### تحديد المستوى للطالب
1. اذهب إلى المستخدمون → جميع المستخدمين
2. انقر على "تحرير" للطالب
3. حدد المستوى من القسم "إعدادات الطالب"

## 📚 إنشاء مقرر جديد

### الخطوات
1. اذهب إلى المقررات → إضافة جديد
2. أدخل عنوان المقرر
3. أدخل محتوى المقرر
4. حدد العلم الشرعي (فقه، حديث، تفسير، إلخ)
5. حدد المستوى المطلوب
6. أضف صورة بارزة
7. في قسم "إعدادات المقرر":
   - أضف رابط كتاب PDF (اختياري)
   - حدد المدة الزمنية
   - أضف أي ملاحظات

### إضافة دروس للمقرر
1. اذهب إلى الدروس → إضافة جديد
2. أدخل عنوان الدرس
3. أدخل محتوى الدرس (الملاحظات النصية)
4. في قسم "إعدادات الدرس":
   - اختر المقرر
   - أضف رابط فيديو YouTube
   - أضف رابط ملف صوتي (اختياري)
   - أضف مرفقات (PDF، روابط، إلخ)
   - حدد ترتيب الدرس

## 🎨 التخصيص

### الألوان
يمكن تخصيص الألوان من خلال تعديل ملف `style.css`:

```css
:root {
    --color-primary: #0B5E3B;      /* اللون الأساسي */
    --color-primary-dark: #084229;  /* لون أغمق */
    --color-accent: #14B171;        /* اللون المميز */
}
```

### الوضع الليلي
يتم تفعيل الوضع الليلي تلقائياً من خلال زر في الرأس. الألوان في الوضع الليلي:

```css
body.dark-mode {
    --color-white: #1a1f2e;        /* الخلفية الداكنة */
    --color-light: #242936;         /* خلفية أفتح */
    --color-dark: #e4e6eb;          /* النص الفاتح */
}
```

## 🔧 الإعدادات المتقدمة

### تعطيل التسجيل العام
التسجيل العام معطل افتراضياً. المدير فقط يمكنه إضافة مستخدمين.

### نظام المستويات
الطلاب يُصنفون حسب المستويات:
- **المستوى 1**: المبتدئون
- **المستوى 2**: المتوسطون
- **المستوى 3**: المتقدمون

الطالب الأعلى مستوى يمكنه الاطلاع على مقررات المستويات الأدنى.

### صلاحيات الوصول
- **الطلاب**: يرون فقط المقررات المسجلين فيها أو المتاحة لمستواهم
- **المعلمون**: يرون جميع المقررات ويمكنهم الإجابة على الأسئلة
- **المدير**: صلاحيات كاملة على كل شيء

## 🐛 حل المشاكل الشائعة

### المشكلة: صفحة تسجيل الدخول لا تعمل
**الحل**: تأكد من أن الصفحة تستخدم قالب "تسجيل الدخول" من إعدادات الصفحة.

### المشكلة: نموذج الاتصال لا يرسل البريد
**الحل**:
1. تأكد من إعداد SMTP بشكل صحيح
2. تحقق من سجل الأخطاء في الخادم
3. استخدم إضافة WP Mail SMTP لاختبار الإرسال

### المشكلة: الفيديو لا يظهر في الدرس
**الحل**:
1. تأكد من أن الرابط من YouTube صحيح
2. تأكد من أن الفيديو عام وليس خاص

### المشكلة: الطالب لا يرى المقرر
**الحل**:
1. تأكد من تسجيل الطالب في المقرر من المقررات → التسجيل
2. تأكد من أن مستوى الطالب يسمح بالوصول للمقرر

## 📄 الصفحات الرئيسية

### صفحة "عن المدرسة" (page-about.php)
صفحة شاملة تعرّف بالمدرسة تحتوي على:
- **Hero Section**: عنوان جذاب مع صورة أو رسم SVG
- **المقدمة**: نبذة تعريفية عن المدرسة
- **Timeline**: خط زمني يعرض مسيرة المدرسة ومراحل تطورها
- **الرؤية والرسالة والقيم**: في بطاقات أنيقة
- **الإحصائيات**: عدد الطلاب، المقررات، الدروس، المعلمين
- **فريق العمل**: عرض الفريق مع الصور
- **CTA**: دعوة للانضمام مع أزرار واضحة

**قابلة للتخصيص بالكامل** من خلال WordPress Customizer، حيث يمكن تعديل:
- نصوص Hero Section
- عناصر Timeline (السنة، العنوان، الوصف)
- الرؤية والرسالة والقيم
- الإحصائيات
- أعضاء الفريق

### صفحة المقال (single.php)
تم تحسينها بشكل شامل مع:
- **Hero Section ضخم**: في أعلى المقال مع الصورة المميزة كخلفية
- **خلفية تلقائية**: إذا لم توجد صورة، يستخدم gradient أخضر جميل
- **العنوان الواضح**: في منتصف Hero بخط كبير وواضح
- **معلومات الكاتب**: صورة واسم الكاتب مع التاريخ ووقت القراءة
- **محتوى محسّن**: تصميم أنيق للمحتوى مع تنسيق جميل
- **تصميم متجاوب**: يتكيف مع جميع أحجام الشاشات
